## Lab 1: Toolchain, Git, and First Pixels

- Set up the development toolchain.
- Create and configure the GitHub repository.
- Create a graphics window of size 800 × 600.
- Display the graphics API version and renderer information.
- Create a mobile interface wireframe in Figma.
- Calculate frame-buffer memory requirements.
- Annotate three human-centred interface decisions.
- Perform the white-screen and black-screen experiment and record observations.

## Lab 2: Fitts' Law Experiment

- Collect movement-time data for different target distances and widths.
- Calculate the Index of Difficulty (ID).
- Calculate median movement times.
- Plot movement time against ID.
- Estimate the Fitts' Law parameters and interpret the results.
- Conduct and analyse the non-dominant-hand experiment.

## Lab 3: Cognitive Analysis of an App

- Audit memory load in a selected application.
- Compare recall and recognition.
- Perform a change-blindness experiment.
- Identify predicted user errors and suitable remedies.
- Observe a classmate using the application and record findings.

## Lab 4: Wireframes and Navigation Flows

- Create a navigation map with labelled transitions and E/V classifications.
- Include failure transitions in the navigation map.
- Create 3–5 grayscale wireframes in Figma.
- Annotate interactive elements and include empty, loading, and error states.
- Calculate the physical touch-target size and convert it to dp.
- Compare the calculated size with platform guidelines.
- Conduct a paper-based usability test with a classmate.
- Record observed navigation differences and answer the interpretation questions.
